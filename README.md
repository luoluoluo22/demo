# Simple Note-Taking Webpage

This project is a simple web-based note-taking application. It allows users to quickly create, view, and delete notes. The notes are stored in the browser's local storage, so they persist across sessions on the same browser.

## Features

*   **Claude Integration:** This project was updated by Claude Code!
*   **Create Notes:** Add new notes using a simple text area.
*   **View Notes:** Display all saved notes.
*   **Delete Notes:** Remove notes that are no longer needed.
*   **Local Storage:** Notes are saved in the browser's local storage, meaning they are available even after closing the browser window (on the same browser and device).

## Files

*   `index.html`: The main HTML file for the webpage structure.
*   `script.js`: Contains the JavaScript logic for note management (adding, displaying, deleting, and local storage interaction).
*   `style.css`: Provides basic styling for the webpage.

## How to Use

1.  Open the `index.html` file in a web browser.
2.  Type your note into the text area.
3.  Click the "Add Note" button to save the note.
4.  Saved notes will appear below the input area.
5.  To delete a note, click the "Delete" button next to the note.
